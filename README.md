# Ghoust Binder

**Ghoust Binder** — это Discord-бот для удаленного управления и розыгрышей на ПК под управлением Windows. Проект работает как локальный скрытый C2 (Command and Control) сервер: бот запускается на компьютере, после чего им можно управлять из любой точки мира через чат в Discord.

⚠️ **Внимание:** Проект создан исключительно в образовательных и развлекательных целях. Не используйте его без согласия владельца компьютера!

---

## 📜 Список доступных команд

Вводите эти команды в чат Discord, где находится бот. К некоторым командам нужно прикреплять файлы (картинки или аудио) прямо в сообщение.

* **`!stop`** — останавливает скрипт и скрыто завершает программу
* **`!show`** `{картинка.png/jpg}` — показать картинку на весь экран
* **`!screen`** — сделать скриншот компа жертвы и отправить в чат
* **`!screamer`** `{картинка.png} {звук.mp3}` — испугать жертву (нужно прикрепить 2 файла)
* **`!popup {текст}`** — показать фейк-ошибку с тролл-текстом
* **`!runaway`** — запустить убегающее от курсора окно
* **`!clipboard`** — прочитать текущий текст из буфера обмена
* **`!openurl {ссылка}`** — открыть указанный сайт в браузере жертвы
* **`!speak {текст}`** — голосовое сообщение на ПК жертвы (голосом робота)
* **`!play`** `{звук.mp3}` — невидимо проигрывает прикрепленный звук на максимуме
* **`!wallpaper`** `{картинка.png/jpg}` — сменяет обои на рабочем столе жертвы
* **`!type {текст}`** — напечатать текст на клавиатуре жертвы (как призрак)
* **`!shake {секунды}`** — начать хаотично дёргать курсор мыши ("пьяная мышь")
* **`!lock`** — отправить компьютер жертвы в спящий режим / заблокировать экран
* **`!desktop`** — мгновенно свернуть все окна на рабочем столе
* **`!error {заголовок}, {текст}`** — фейковая системная ошибка Windows
* **`!cd open`** / **`!cd close`** — открывает или закрывает лоток дисковода
* **`!taskbar hide`** / **`!taskbar show`** — скрывает или возвращает панель задач Windows
* **`!bsod10`** — фейковый экран смерти (Windows 10). *Закрывается кнопкой Escape.*
* **`!bsodxp`** — фейковый экран смерти (Windows XP). *Закрывается кнопкой Escape.*

## 🛠️ Установка и запуск

### 1. Требования

Убедитесь, что у вас установлен **Python 3.8** или новее. Установите необходимые библиотеки через терминал:

```bash
pip install discord.py pygame Pillow pyttsx3 keyboard pyautogui
```

### 2. Настройка бота

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications) и создайте нового бота.
2. В разделе "Bot" **обязательно** включите галочку **Message Content Intent**.
3. Скопируйте токен бота и вставьте его в файл `Main.py` в переменную `TOKEN = 'ТВОЙ_ТОКЕН'`.
4. В коде найдите функцию `@bot.check(is_owner)` и замените никнейм на свой точный ник в Discord. Это защитит бота от посторонних.

### 3. Запуск

Запустите скрипт на целевом компьютере:

```bash
python Main.py
```
*Совет: Для скрытой работы без окна консоли скрипт можно скомпилировать в .exe с помощью PyInstaller (флаг `--noconsole`).*
